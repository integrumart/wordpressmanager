# Changelog

## Version 20.0
* Added support for multiple saved site profiles.
* Added ability to write posts in Markdown.
* Added Media Upload, Manage Content (Edit/Trash), and Reply to Comments features.
* Removed external `requests` library to guarantee full 64-bit and 32-bit Python cross-compatibility for NVDA 2026.1 and NVDA 2025.x.
* Restructured add-on architecture to conform to standard NVDA Add-on template.
* Added Indonesian language support.
