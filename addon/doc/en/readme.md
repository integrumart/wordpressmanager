# WordPress Manager for NVDA

A professional NVDA add-on that brings the power of WordPress management directly to your fingertips via REST API.

---

## 🌟 Overview

**WordPress Manager** is a high-performance, accessible tool designed for visually impaired content creators and webmasters. It eliminates the need for complex web browsers and heavy editors by allowing users to manage their WordPress sites directly through NVDA.

## ✨ Key Features

* ✍️ **Instant Content Creation & Editing:** Create and edit Posts and Pages without opening a browser. Supports Plain Text, HTML, and Markdown format.
* 🗂️ **Content Management:** Easily view recent posts/pages, edit them, or move them to trash.
* 🖼️ **Media Uploader:** Upload files and images directly to your WordPress Media Library via Windows File Picker. The uploaded file URL is automatically copied to your clipboard.
* 🔄 **Multi-Site Support:** Save multiple website profiles and switch between them effortlessly.
* 🏷️ **Dynamic Category Support:** Fetches and displays your site's categories in real-time.
* 💬 **Comment Moderation:** Approve, spam, trash, and directly reply to comments with simple shortcuts.
* 🚀 **Asynchronous Performance:** Built with multi-threading to ensure NVDA never freezes during network operations.
* 🔒 **Secure Authentication:** Uses WordPress Application Passwords to keep your main credentials safe.
* 🌍 **Localization:** Full support for English, Turkish, and Indonesian.

## 🛠️ Installation

1. Download the latest `.nvda-addon` from the [Releases](link_to_releases) page.
2. Open the file to install it in NVDA.
3. Restart NVDA when prompted.

## ⚙️ Configuration

1. Go to **NVDA Menu > WordPress Manager > Settings**.
2. Select an existing profile or fill out the form to add a new one.
3. Enter your **WordPress Site URL** (e.g., `https://your-site.com`).
4. Enter your **Username**.
5. Enter your **Application Password** (Generate this in WordPress: Users > Profile > Application Passwords).
6. Click **Save Profile** to store these credentials for future use.
7. Assign your preferred shortcuts in **NVDA Menu > Preferences > Input Gestures**.
