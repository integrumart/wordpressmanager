WordPress Manager untuk NVDA

Add-on NVDA profesional yang menghadirkan kekuatan manajemen situs WordPress langsung di ujung jari Anda melalui REST API.

🌟 Gambaran Umum

WordPress Manager adalah alat yang sangat cepat dan aksesibel, dirancang khusus untuk pembuat konten dan pengelola web tunanetra. Add-on ini mengeliminasi kebutuhan penggunaan web browser yang rumit dan editor teks yang berat, karena Anda dapat mengelola berbagai situs WordPress Anda langsung melalui antarmuka NVDA.

✨ Fitur Utama

  • ✍️ Pembuatan & Pengeditan Konten Instan: Buat dan edit Postingan maupun Halaman tanpa membuka browser. Mendukung format Teks Biasa (Plain Text), HTML, dan Markdown.
  • 🗂️ Manajemen Konten: Lihat daftar artikel dan halaman terbaru, edit isinya, atau buang ke keranjang sampah (trash) dengan mudah.
  • 🖼️ Pengunggah Media (Media Uploader): Unggah berkas gambar maupun dokumen langsung ke Pustaka Media WordPress Anda melalui jendela File Picker Windows. URL dari berkas yang berhasil diunggah akan secara otomatis tersalin ke clipboard (papan klip) Anda.
  • 🔄 Dukungan Multi-Site: Simpan beberapa profil kredensial situs web dan beralih antar situs dengan mudah.
  • 🏷️ Dukungan Kategori Dinamis: Mengambil dan menampilkan daftar kategori di situs Anda secara real-time.
  • 💬 Moderasi Komentar: Setujui, tandai spam, hapus, dan balas komentar secara langsung menggunakan tombol pintas sederhana.
  • 🚀 Performa Asinkron: Dibangun dengan sistem multi-threading untuk memastikan NVDA tidak pernah membeku (freeze) selama memproses data jaringan internet.
  • 🔒 Autentikasi Aman: Menggunakan Fitur Sandi Aplikasi (Application Passwords) WordPress untuk menjaga kata sandi utama Anda tetap aman.
  • 🌍 Lokalisasi: Dukungan penuh untuk bahasa Inggris, Turki, dan Indonesia.

🛠️ Instalasi

  1. Unduh file .nvda-addon terbaru dari halaman Releases.
  2. Buka file tersebut untuk menginstalnya ke dalam NVDA.
  3. Muat ulang (Restart) NVDA jika diminta.

⚙️ Konfigurasi

  1. Buka Menu NVDA > WordPress Manager > Settings.
  2. Pilih profil situs yang sudah ada atau isi formulir untuk menambahkan yang baru.
  3. Masukkan WordPress Site URL Anda (contohnya, https://situs-anda.com).
  4. Masukkan Username Anda.
  5. Masukkan Application Password Anda (Buat kata sandi aplikasi ini dari Dasbor WordPress Anda: Pengguna > Profil > Kata Sandi Aplikasi).
  6. Klik Save Profile untuk menyimpan data situs tersebut agar bisa digunakan nanti.
  7. Anda dapat mengatur tombol pintasan pintasan sesuai selera Anda melalui menu NVDA > Pengaturan > Tombol Pintasan... (Input Gestures).
